AI Auto Editing Studio Ultimate

Project Overview

AI Auto Editing Studio Ultimate is a unified AI-powered Android video production application designed to automate the complete video creation process, from the initial idea to the final rendered production.

Main Objective

Build a professional native Android APK application using Kotlin and Jetpack Compose.

The application must operate as one fully integrated AI production ecosystem, not as a collection of disconnected tools.

Core Features

1. AI Niche Discovery and Trend Analysis
2. AI Video Ideas and Topic Research
3. Automatic Hook, Script, Titles and CTA Generation
4. Complete Storyboard and Shot Planning
5. AI Character and Environment Design
6. Global Visual Bible and Character Consistency Lock
7. Automatic Image and Video Prompt Engineering
8. AI Image and Video Generation
9. Seamless Video Continuity and Last-Frame Connection
10. Voice Generation, Dubbing and Subtitles
11. Automatic Video Editing and Timeline Assembly
12. AI Quality Control and Automatic Error Repair
13. Long-Form Video Production
14. Automatic Shorts and Reels Generation
15. Thumbnail, Description, Hashtags and Publishing Preparation

Core Architecture

- Native Android application: Kotlin + Jetpack Compose.
- Backend: Python + FastAPI.
- AI orchestration and production pipeline.
- Unified project database and asset management.
- Provider-independent AI integration.
- Background processing and GPU rendering.
- GitHub Actions for automated Android builds.

Non-Negotiable Requirements

- All engines must be interconnected through shared project data and APIs.
- Preserve character identity, environment, visual style and approved production settings.
- Connect consecutive video clips using previous scene state and last-frame references when supported.
- Support automatic workflow execution and project resumption.
- Avoid rebuilding completed stages unnecessarily.
- Keep AI provider credentials secure on the backend.
- Deliver the final product as an Android APK, not a website.

Development Instructions

Continue developing the existing repository. Do not replace it with a new project.

Inspect the existing architecture and preserve all working files. Implement the system incrementally, test every milestone, and maintain compatibility between all modules.

The final goal is a complete, professional, fully integrated AI video production studio.
